# Data

## Main source
The study uses CEPII BACI HS2012 V202601 bilateral merchandise-trade data for 2015–2024.

## Included derivative dataset
`Russia_BACI_Lite_Dataset.zip` is a study-specific Russia-focused derivative dataset used by the replication notebook. Before making this file public, confirm that redistribution is permitted under the applicable CEPII BACI terms. If redistribution is not permitted, keep the file private and provide only the code required to regenerate it from BACI obtained from the original provider.

## HS6 product codebook
`product_codebook/Russia_HS6_Full_Product_List_Study_v1.0_with_descriptions.csv` contains the HS2/HS4/HS6 hierarchy and English descriptions used for study documentation. The descriptions were populated from the official UN Comtrade HS2012 (H4) reference structure.
