# Data input

Raw CEPII BACI files are intentionally not redistributed in this repository.

The full workflow accepts either:

1. `Russia_BACI_Lite_Dataset.zip` generated by the structural master workflow, or
2. the official `BACI_HS12_V202601.zip` archive obtained from CEPII.

For Google Colab, upload the data ZIP to `/content`, `/content/BACI`, or place it under `/content/drive/MyDrive/BACI`. The full notebook searches these locations automatically.

The repository already contains the **executed derivative results** used in the final manuscript under `results/`. Those files are provided for verification and manuscript-result consistency checks; reproducing them from raw BACI requires the source data above.

Do not commit or redistribute raw BACI archives unless the data provider's terms explicitly permit redistribution.
