# Data

This repository includes the study-specific derivative dataset:

- `Russia_BACI_Lite_Dataset.zip`

The archive contains Russia-focused derivative Parquet files generated from **CEPII BACI HS2012 V202601** for 2015–2024. It is not the complete BACI source archive.

Contents:
- `russia_import_partner_hs6_year.parquet`
- `russia_export_partner_hs6_year.parquet`
- `russia_import_hs6_year_summary.parquet`
- `russia_export_hs6_year_summary.parquet`
- `china_world_trade_year.parquet`
- `metadata.json`

The full BACI source archive is not included. Users who wish to reconstruct the derivative dataset from the original source should obtain the corresponding BACI release from CEPII and follow the extraction procedures in the notebook.

Before making the repository public, the repository owner should confirm that redistribution of the derivative dataset is consistent with the applicable CEPII/BACI terms of use and citation requirements.
