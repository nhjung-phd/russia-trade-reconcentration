# Data and Code Availability

The trade data used in this study were obtained from the CEPII BACI database (HS2012, V202601). A study-specific derivative dataset, replication code, analysis notebooks, statistical outputs, tables, and figures are archived in the project repository at:

https://github.com/nhjung-phd/russia-trade-reconcentration

The replication package includes procedures for data extraction and preprocessing, partner-share and trade-concentration analyses, HS6-level distributional tests, balanced-partner and denominator-sensitivity analyses, fixed-effects and random-effects panel estimations, Hausman specification tests, HS6 product fixed-effects year profiles, PPML estimations with high-dimensional fixed effects, and robustness checks.

The repository is currently maintained as a private repository during manuscript review. Access may be provided to editors and reviewers upon request. The repository will be made publicly accessible following the journal's data and code availability requirements.
