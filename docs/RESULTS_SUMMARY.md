# Verified Results Summary

These values are taken from the executed No-DID replication outputs included in `results/`.

## Structural results
- China share of Russian imports: 23.86% (pre) → 53.65% (post), **+29.80 percentage points**.
- Balanced-partner China import share: **+28.00 percentage points**.
- Bank of Russia denominator sensitivity: China import share rises from 24.14% (2021) to approximately 37% in 2023–2024; the increase is about **+12.89 percentage points**.
- Import HHI: 0.0827 → 0.2987.
- Import effective number of partners: 12.16 → 3.38.

## HS6 distributional results
- Mean change in China import share: **+23.94 percentage points**.
- HS4-cluster bootstrap 95% CI: **[22.54, 25.33] percentage points**.
- China share increased in 73.6% of import HS6 products.

## Longitudinal panel robustness
- Partner-year FE China×Post: **+30.49 pp (imports)** and **+19.82 pp (exports)**.
- Hausman: Import χ²(5)=74.99, p<.001; Export χ²(5)=133.96, p<.001.
- HS6 product-FE profiles show a gradual pre-2022 rise in China import share and a sharp acceleration after 2022.

## PPML-HDFE
- Import China×Post: β=1.613, 95% CI [1.190, 2.035], p<.001.
- Export China×Post: β=2.232, 95% CI [1.632, 2.832], p<.001.
- `exp(β)-1` is a conditional relative shift versus EU27, not the absolute growth rate of bilateral trade.

## Interpretation
The evidence supports broad China-centered import re-concentration and value-concentrated export-market reorientation. The analysis is structural and longitudinal, not a causal estimate of sanctions.
