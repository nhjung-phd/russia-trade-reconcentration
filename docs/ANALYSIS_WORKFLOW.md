# Analysis workflow

1. Load the light BACI analytical dataset.
2. Audit France, Italy, and EU27 codes.
3. Calculate partner shares.
4. Calculate country-level concentration.
5. Recalculate concentration with EU27 aggregated as one geopolitical bloc.
6. Estimate HS6 pre/post partner-share changes.
7. Calculate HS6 distributional tests and clustered bootstrap summaries.
8. Measure China import dependence thresholds.
9. Measure EU27 decline / China increase co-movement.
10. Repeat relevant analyses excluding HS27 energy products.
11. Build balanced-partner samples.
12. Calculate focal-partner pre/post shifts and placebo ranks.
13. Recalculate country and bloc concentration on balanced samples.
14. Run Bank of Russia denominator sensitivity using aligned pre/post windows.
15. Build balanced-HS6 longitudinal profiles relative to 2021.
16. Run auxiliary revised PPML-HDFE where computationally feasible.
17. Generate all figures without internal top titles.
18. Export CSV tables, workbook, logs, manifest, and ZIP archive.
