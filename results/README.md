# Corrected analysis outputs

This folder contains outputs from the corrected v2.1 reanalysis.

## Tables

`tables/` contains all CSV outputs from the corrected run, including:

- country-code audit and EU27 membership used;
- annual and pre/post concentration measures;
- major partner-group shares;
- HS6 distributional statistics;
- China-dependency thresholds;
- EU27-China co-movement;
- non-energy analysis;
- top-100 HS6 changes by focal partner;
- observed partner counts;
- balanced-partner panels and placebo ranks;
- balanced concentration sensitivity;
- Bank of Russia denominator sensitivity;
- balanced-HS6 longitudinal profiles;
- auxiliary revised PPML-HDFE outputs;
- compact manuscript-facing summary.

## Workbook

`workbooks/Russia_Trade_Corrected_Reanalysis_All_Tables.xlsx` combines the analysis tables in one workbook for review convenience.

## PPML convergence

The corrected import PPML-HDFE did not converge. This is an observed computational result, not missing documentation. Do not substitute earlier PPML estimates into the corrected analysis without an explicitly documented specification change.
